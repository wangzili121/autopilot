# 当前状态与效果

更新日期：2026-09-07

## 当前结论

项目已经具备自动优化控制面的主要软件骨架，也在 Conditional IS 上找到过
有价值的配置交互和 stage wavefront 机制。但“稀疏测量驱动的自动优化器在
真实 NPU 上用更少实验超过人工最优”这一核心产品结论尚未完成验证。

## 已实现的软件能力

| 模块 | 状态 | 当前能力 |
| --- | --- | --- |
| Inference Graph IR 与 Conditional IS 适配器 | 已实现 | 描述 candidate、proposal、target scoring、reward 和 selection 阶段 |
| 搜索空间编译器 | 已实现 | 参数类型、阶段归属、依赖、能力约束和稳定 candidate hash |
| 校准与证据账本 | 已实现 | ABBA 计划、源码/模型/配置绑定、证据分级和质量门禁 |
| 主机干扰与执行门禁 | 已实现并设备验证 | 识别共享主机进程变化，拒绝污染测量，估算重试和生命周期成本 |
| 图捕获规划 | 已实现并设备验证 | 从阶段 shape 分布选择 ACL Graph bucket，并检查运行时闭包 |
| 离线策略选择与主动采样 | 已实现 | 结合不确定性、潜在收益、距离和配置切换成本选择候选 |
| 迁移、holdout 与运行时路由 | 已实现 | 不在支持域时拒绝激活，路由到已验证预热 endpoint 或人工基线 |
| stage wavefront admission | 已实现并设备验证 | 按阶段、序列和 token 容量组织 proposal 调用 |
| AIC-NPU 阶段成本模型 | 已实现，待真实校准 | 对 stage × batch × shape bucket 拟合稀疏仿射模型和不确定区间 |
| 双层执行 trace | 已实现 | 区分算法调用排队和真正进入 backend 的 batch；尚非 kernel trace |

当前测试集包含 268 个测试用例。它证明契约和控制逻辑的行为，但不能替代
真实 NPU 性能验证。

## 已获得的主要实验信号

### 1. 容量参数具有明显的负载依赖和跨层交互

短上下文高压力下，历史强配置相对 `40/96` 基线的 ABBA 配对结果为：

| 配置 | 两个配对效果 | 几何平均 | 判断 |
| --- | --- | ---: | --- |
| `128/768`，token `32768/131072` | +9.08%、+6.86% | +7.97% | 超过 4.30% 重放噪声 |
| `256/896`，token `65536/147456` | +14.11%、+6.07% | +10.02% | 超过 4.30% 重放噪声 |

但高容量配置之间的直接比较只有 `+1.07%`，小于该次 `5.61%` 重放噪声，
因此不能证明 `256/896` 普遍优于 `128/768`。这也是优化器必须把上下文、
并发、实际 shape 和图覆盖纳入特征，而不能固化一个全局最优值的原因。

一次耦合实验中，`40/64 + graph64` 相对 `40/48 + graph48` 的中位收益为
`+14.19%`，而只把 `graph48` 改为 `graph64` 的中位效果是 `-1.22%`。
这说明序列容量与图覆盖存在交互，独立逐参数扫描会得出错误结论。

### 2. 已有一个通过独立 holdout 的短上下文策略

短上下文 P32 的 `40/64 + graph64` 策略在独立 holdout 中，相对
`40/48 + graph48` 的两个配对收益为 `+13.22%` 和 `+11.83%`；均值 QPS
为 `0.3130` 对 `0.2794`，提升 `+12.02%`。该结果支持这个具体 workload
cohort，不代表可直接迁移到 medium2k 或其他算法。

迁移到 medium2k P32 后，中位收益只有 `+2.85%`，低于 `3.91%` 的同批
重放噪声；把 base token budget 从 10240 提至 12288 还出现 `-6.45%`
中位回退。这进一步确认策略与上下文长度相关。

### 3. stage wavefront 是目前最有技术含量的机制结果

短上下文 P96 中，proposal engine 的 mixed prefill/decode step 曾占
`79.41%`。stage wavefront 将 proposal 图命中率提高到约 `96%`，初始两对
实验的 QPS 几何平均提升 `10.65%`。后续正式两对实验的 QPS 几何平均提升
`18.04%`，forward-slot rate 提升 `18.09%`。

其效果并非所有上下文都成立。medium-context 的串行 sharding 回退
`59.20%`，bounded pipeline 回退 `2.00%`；per-sequence credit release
出现表面 `+7.06%`，但同配置重放本身可出现 `+16.26%`，因此未形成有效
收益声明。当前结论是：短上下文 wavefront 值得保留，长上下文需要新的
流水与稳定测量设计，不能直接激活。

### 4. 其他历史优化信号

- native categorical sampler 曾测得约 `+11.5%`；它来自早期独立实验，
  尚未作为当前自动选择器的正式组合收益重新验证。
- selected-token scoring 短上下文约 `+2.8%`，长上下文通过 tiled reduction
  解决过 OOM；收益较小且新版框架已有部分相关实现，当前不是主线成果。
- memory split 约 `+0.6%`，低优先级。
- ACL Graph 是重要搜索维度，但收益依赖 shape 覆盖、容量和上下文，不能用
  一个统一百分比描述。

## 尚未完成的关键部分

1. `engine_batch_timeline` 还没有严格转换成真实 AIC-NPU 校准语料。
2. 当前 AIC-NPU 示例数据是合成数据，尚无真实 bucket MAPE、排序准确率和
   OOD 拒绝结果。
3. 尚未证明主动选择 8 至 12 个测点能以等预算胜过随机搜索或规则网格。
4. 尚未产出一个由成本模型推荐、再在独立 holdout 上超过强人工基线的完整
   策略包。
5. stage-pressure 动态 token budget 和 TAPER 类 branch admission 仍处于规划，
   后者需要先证明 Chang 算法能暴露满足语义要求的 branch/slack 接口。

因此，对项目最准确的评价是：基础设施和一个短上下文运行时机制已经有实质
内容，自动调优的核心闭环仍差真实成本模型校准与等预算端到端对照实验。
