# Inference Autopilot 项目概览

## 一句话定位

Inference Autopilot 是一个面向 inference scaling 工作流的自动优化控制面：
它把算法执行路径表达为带语义约束的计算图，把部署配置和运行时策略编译成
合法候选，用少量可信实验建立性能模型，最终输出可复现、可回退的策略包。

项目目前独立开发，成熟后以插件或适配器形式接入 Muyuan。首个目标算法是
Chang 仓库中的 `conditional_is_small_proposal`，但中间表示、搜索、实验和
策略协议不绑定某一种 inference-scaling 算法。

## 为什么不是普通参数扫描器

只遍历 `max_num_seqs` 和 `max_num_batched_tokens` 很容易实现，但无法处理
Conditional IS 的多阶段负载、图捕获离散边界、配置重启成本、共享主机污染、
跨上下文迁移以及算法语义约束。本项目的优化闭环是：

```text
算法适配器 + 工作负载 + 环境能力
  -> Inference Graph IR
  -> 约束化搜索空间
  -> 阶段和 shape bucket 成本模型
  -> 决策关键的少量设备实验
  -> 独立 holdout 与安全门禁
  -> 静态配置 + 运行时策略 + 回退条件组成的策略包
```

这使优化器可以回答的不只是“哪个数字最快”，还包括：

1. 哪个算法阶段受到序列容量、token 容量、图覆盖或内存约束；
2. 哪些候选在启动前就不合法或不值得测；
3. 下一次 NPU 实验最能减少哪个决策的不确定性；
4. 一个短上下文策略能否迁移到另一并发量或上下文长度；
5. 运行中何时可以切换策略，何时必须退回人工基线。

## 参数与机制范围

当前优化空间分为四层：

| 层 | 例子 | 变更时机 | 当前处理方式 |
| --- | --- | --- | --- |
| 静态部署 | 两个引擎的序列容量、token budget、内存比例 | 引擎重启 | 离线搜索 |
| 图捕获 | ACL Graph 模式、bucket 列表、capture ceiling | 引擎重启 | 独立规划与覆盖约束 |
| 热策略 | batch wait、评分优先级、stage wavefront | 请求或策略边界 | 门禁后动态选择 |
| 算法语义 | candidate、rollout、block size、校正模式 | 显式算法边界 | 分 cohort，不与部署收益混算 |

后续还可接入 TP/DP/PP、模型副本和角色放置、KV 配额、量化/编译变体、
prefill/decode 资源划分等，但每个参数必须先声明依赖、合法域、变更成本和
遥测可观测性，才能进入搜索空间。

## 已有的非配置优化

项目不只搜索配置，还实现了 Conditional IS stage wavefront admission。
它识别 proposal rollout 这一算法操作边界，在序列和 prefill-token 两个容量
约束下合并就绪调用，减少 prefill/decode 混跑并提高 ACL Graph 命中率。
vLLM 仍负责 token 调度，Autopilot 不替代通用 serving scheduler。

项目也包含 selected-token scoring 的规划与 NPU 探针，用于判断完整 logits
物化和归约是否值得替换。但现阶段它是能力与机制验证项，不能笼统声称为
vLLM 尚不存在的通用优化；不同 vLLM/vLLM-Ascend 版本必须单独审计。

## 最终产品形态

预期交付物由五部分组成：

1. **算法适配器 SDK**：把新算法映射到统一阶段图、语义不变量和可调字段。
2. **自动校准器**：读取历史证据并选择少量设备测点，记录完整环境和源码哈希。
3. **成本与策略引擎**：预测候选的吞吐、延迟、内存、失败风险和切换成本，
   在 SLO 下选择策略。
4. **运行时控制器**：根据上下文、并发和阶段压力，在已验证策略池内路由，
   超出支持域时自动回退。
5. **可审计策略包**：保存静态配置、图计划、热策略、适用范围、证据和回滚项，
   可导出给 Chang runner，未来也可作为 Muyuan infra 插件使用。

产品是否成立，最终不由代码量决定，而由三个结果决定：使用明显少于网格搜索的
真实设备实验；在未参与拟合的工作负载上达到或超过强人工基线；发生负载或环境
漂移时能够拒绝不可靠推荐并安全回退。
