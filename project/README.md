# 项目进展中心

本目录集中维护 Inference Autopilot 的项目定位、当前进展、实测效果和
后续路线。它回答“项目要做成什么”“现在真正完成了什么”“哪些效果已经
可信”“下一步为什么这样做”四类问题。

## 文档导航

- [项目概览](PROJECT_OVERVIEW.md)：目标、产品形态、工作边界和核心技术路线。
- [当前状态与效果](CURRENT_STATUS.md)：截至 2026-09-07 的实现、实验结果、
  证据等级和主要缺口。
- [路线图](ROADMAP.md)：按照近期成果、设备验证、运行时优化和产品化拆分的
  工作计划与验收条件。
- [进展日志](PROGRESS_LOG.md)：重要里程碑、决策和后续更新规则。

## 状态口径

为避免把原型能力写成最终成果，本文档统一使用以下状态：

| 状态 | 含义 |
| --- | --- |
| 已实现 | 代码、CLI 或契约已经存在，并有自动化测试 |
| 已设备验证 | 已在目标 NPU 栈运行并获得可复现数据 |
| 已形成有效证据 | 效果通过配对实验、重放噪声、质量和环境门禁 |
| 待验证 | 设计或实现存在，但尚不能主张真实性能收益 |
| 规划中 | 尚未实现，只有明确方案和验收条件 |

实验细节仍以 [`docs/`](../docs/) 中的原始实验日志为准；论文依据和相关工作
以 [`papers/`](../papers/) 为准。本目录提供面向项目管理的凝练视图，不替代
原始证据。
